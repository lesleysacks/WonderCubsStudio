# Future Architecture

The next architectural priority is reliable asset storage and management.

- v0.4 starts with Image Manager, followed by Voice Manager on the same asset conventions.
- The AI Agent Engine follows only after assets have stable identifiers, storage locations, lifecycle rules, and selection APIs.
- Publishing integration and analytics follow the automation foundation.
- A one-click production pipeline remains a v1.0 goal after each component workflow is independently reliable.

Future modules should preserve the existing UI, controller, service, repository, and persistence boundaries. This document is directional and does not claim these features are implemented.
